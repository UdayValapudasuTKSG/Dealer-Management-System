# Layer 2 — Contacted (24h SLA) Sales Advisor

**🚦 Flow (step-by-step, lowest level)**

- **1. Lead lands in phase `contacted`-eligible.** On A2 round-robin assign (Layer 1), `leads.stageEnteredAt` is stamped and the **24h contact SLA** clock starts. Advisor opens `GET /api/leads/:id/review` (the single merged Workflow console — the old standalone "Run Review" readiness view is folded in here, not a separate page). All reads are `activeDealerId(res)`-scoped via `x-dealer-id`; a lead outside the active dealer/division 404s.
- **2. Advisor sees SLA countdown** derived from `stageEnteredAt + 24h` (America/Guyana GMT-4). Amber at <6h remaining, red on breach. **A7 Outreach composer** has pre-drafted a first-touch message; advisor reads the `agent-brief` panel.
- **3. Click-to-call.** Advisor hits Call → frontend requests `GET /api/telephony/token` then `GET /api/telephony/config` to pick provider. If Twilio Voice browser calling is configured → dial in-browser; else **StubTelephonyAdapter** logs a manual-call shell. Every attempt creates a `call_logs` row (provider `twilio`|`stub`) via `POST /api/leads/:id/calls`.
- **4. Log the call outcome + note.** Advisor writes disposition (connected / no-answer / voicemail / wrong-number / callback) and a free-text summary. The summary is stored and any inbound-quoted customer text is wrapped with `guardUntrusted` before it ever reaches an agent.
- **5. A6 Call sentiment fires (fire-and-forget).** On note save it auto-runs; advisor may also force `POST /api/leads/:id/calls/:cid/suggest-sentiment`. A6 is a declared, audited, kill-switchable autonomous-write agent — writes `call_logs.sentiment` only if `agents.status='active'` and confidence ≥ `MIN_AGENT_CONFIDENCE`; below floor it routes to human (leaves sentiment null + flags for review).
- **6. Conversation notes.** Non-call touches (WhatsApp/email recap) go to `POST /api/leads/:id/notes` → `comm_notes`/`timeline_events`. A `call_log` and a note are distinct rows.
- **7. 4-call cadence scheduling.** On each unconnected attempt the system schedules the next `task` per cadence **24h → +3d → +3d → +7d** (attempts 1-4). Each due task is dealer-scoped and shows in the advisor queue.
- **8. Branch A — connected & interested:** advisor advances via the **single primary CTA "Advance to Qualified"** → `POST /api/leads/:id/advance`. The versioned `stage_checklists` gate for this transition requires **≥1 logged call with a disposition**; if absent → `422 {unmet:[...]}` and the CTA stays disabled with reasons listed inline (this is the "Readiness check", not manager Approvals, not an AI run).
- **9. Branch B — 4 attempts exhausted / not interested:** advisor closes with reason → `POST /api/leads/:id/decision` (or `PATCH /api/leads/:id` status=`lost`) with mandatory `reason` + `reasonDetail`. Timeline event recorded.
- **10. Every action** appends a `timeline_events` row (`isAgent` true for A6/A7, false for human) visible in `GET /api/leads/:id/timeline`.

**⚙️ Agents in play**

- **A6 Call sentiment** (claude-sonnet-4-6) → **trigger:** fire-and-forget on `call_logs` note save + manual `/suggest-sentiment` → **grounded inputs:** the single `call_logs.note` row (PII-minimized, wrapped in `guardUntrusted`) for this lead within active dealer only → **output:** `{sentiment, confidence}` written back to `call_logs.sentiment` → **HITL:** autonomous-write BUT gated — declared in `agents`, kill-switch `isAgentEnabled`, every run in `agent_runs(runType='sentiment')`; if `confidence < MIN_AGENT_CONFIDENCE` it does NOT write, routes to human (advisor sets sentiment manually).
- **A7 Outreach composer** → **trigger:** advisor opens console / `GET /leads/:id/agent-brief` → **grounded inputs:** lead row, prior `comm_notes`, `call_logs` dispositions, `aiScore` (all dealer-scoped) → **output:** `{headline, riskLevel, actions[], draftMessage}` → **HITL: yes, always** — never auto-sends; advisor must "Approve & Send" via `/outreach` or `/whatsapp`.
- **A15 Pipeline suggestions** (read-only) → surfaces this lead in the advisor's "act now" list via `GET /pipeline/suggestions` when SLA nears breach or a callback is due → **HITL:** advisory only, no write.

**🧠 AI for the persona**

- **Draft first-touch message** (A7 `draftMessage`) tuned to channel and lead source/interestedVehicle — advisor edits then approves.
- **Risk + next-best-action:** `riskLevel` and `actions[]` (e.g. "call now, SLA 3h left", "send spec sheet for selectedModel").
- **Sentiment chip** per call (A6) — positive/neutral/negative badge on each `call_logs` row; low-confidence runs show "needs your read" instead of a guessed value.
- **Sentiment digest** across recent notes via `GET /dashboard/sentiment` (≤40 real dealer-scoped notes) for the advisor's book.

**🔑 Key fields · validations · SLA**

- **SLA:** contact within `stageEnteredAt + 24h` (GMT-4). Breach → amber<6h, red at 0; breach fires `notify-owner` to `reportingManagerUserId`. Timer resets on stage change only, not on each call.
- **Cadence tasks:** attempt 1 = +24h from stageEntered, attempt 2 = +3d, attempt 3 = +3d, attempt 4 = +7d. After attempt 4 with no connect → auto-suggest close reason `no_contact`.
- **call_logs:** `direction`, `provider`∈{twilio,stub}, `disposition` (required, enum), `durationSec` (≥0), `sentiment` (nullable), `callbackAt` (must be future, GMT-4).
- **Advance gate** (versioned `stage_checklists`, contacted→qualified): requires ≥1 `call_logs` row with a non-null disposition. Missing → `422 unmet[]`. This is the "Readiness check" — distinct from manager `gates` (Approvals) and agent `agent_runs` review (Approve/Override).
- **Close reason** mandatory on `decision`: enum `reason` + free `reasonDetail`.
- **guardUntrusted** wraps every quoted customer utterance / inbound text before A6/A7 ingestion; PII minimized on the agent call.
- **Config:** `MIN_AGENT_CONFIDENCE` floor; `agents.status` kill-switch; telephony `provider` auto-select.

**🔀 Edge-of-edge cases → handling**

| Scenario | Detection | Handling | Owner | HITL? |
| --- | --- | --- | --- | --- |
| Advance clicked with zero logged calls | `stage_checklists` gate on POST /advance | 422 `{unmet:['no_logged_call']}`; CTA stays disabled, reason shown inline in Readiness panel | System | Yes — advisor must log a call |
| 24h SLA breach | Cron/lazy check `stageEnteredAt+24h < now` | Lead flagged red; `notify-owner` → reportingManager; A15 surfaces in pipeline | System→Manager | Manager visibility, advisor acts |
| Twilio token fetch fails / voice down | 503 from `/telephony/token` | Fall back to `StubTelephonyAdapter`; advisor dials manually, still logs `call_logs` provider=stub | System | Yes — manual dial |
| A6 sentiment below confidence floor | `confidence < MIN_AGENT_CONFIDENCE` | No write to `call_logs.sentiment`; run recorded `routedToHuman`; UI shows "needs your read" | Agent→Advisor | Yes |
| A6 agent paused (kill-switch) | `agents.status='paused'` | 409 on `/suggest-sentiment`; auto-run skipped; sentiment left null, no error to advisor flow | Admin | N/A (manual only) |
| WhatsApp/email opt-out on outreach | opt-out flag on contact / dedupe | `/outreach` returns 409; block queue; suggest call channel instead | System | Yes — advisor picks alt channel |
| Outbound message delivery failed | `email_logs` outbox retry/backoff exhausted | Mark failed after backoff; notify advisor; do NOT auto-resend beyond policy | Outbox worker | Advisor retries |
| Duplicate call log (double-click / retry) | Same `lead+timestamp+duration` within window | Debounce; second POST dedup'd; single `timeline_events` row | System | No |
| Concurrent advance by two advisors | Optimistic version / idempotencyKey on advance | First wins (200); second gets no-op or 409; single stage transition | System | No |
| Cross-tenant lead access | `activeDealerId` scope mismatch | 404 (never leak existence); audit-log the denied access, dealer-scoped | System | No |
| Callback time in the past | Validation `callbackAt ≤ now` (GMT-4) | 400; reject; ask advisor to pick future slot | System | Yes |
| Wrong-number / dead lead before cadence ends | disposition=`wrong_number` | Allow early close via `decision` reason; skip remaining cadence tasks | Advisor | Yes |
| Prompt-injection in customer note | Untrusted text pattern | `guardUntrusted` wrapper neutralizes; A6/A7 treat as data not instruction | System | No |
| Lead reassigned mid-cadence (round-robin churn) | ownerUserId change | Open cadence tasks re-owned to new advisor; SLA clock unchanged (stageEnteredAt persists) | System | No |
| Inbound call arrives (customer calls back) | webhook `/webhooks/twilio/voice` | Create `call_logs` direction=inbound; dedup by `webhook_events` idempotency; attach to lead | System | Advisor logs outcome |
| Division mismatch (CAM vs GT) | `divisionId` on lead vs advisor | Scoped out of advisor's queue; visible only to correct division/manager | System | No |

**📄 Documents & PDF format**

- **No PDF is generated at Layer 2** — this stage produces communications and logs, not documents. (Quote PDF is a Layer 3+ artifact via `quote-pdf.ts` / pdfkit.)
- **Outreach message (consumed/produced):** A7 `draftMessage` → advisor-approved → delivered via **email_logs unified outbox** (nodemailer Gmail SMTP for email; Meta Cloud API v21 / Twilio auto-select for WhatsApp), with retry/backoff/`dedupeKey`. Body = greeting + `selectedModel`/`interestedVehicle` reference + CTA + advisor signature block. HTML email template rendered server-side; WhatsApp = plain text within session window.
- **Call recording / transcript (if Twilio):** `recordingUrl` stored on `call_logs`, served via dealer-scoped presigned GCS URL (per-object ACL) — never a public link.
- **Timeline export** (screen artifact, not PDF): chronological `timeline_events` list — call dispositions, sentiment chips (`isAgent`-flagged), notes, outreach sends — dealer-scoped.
