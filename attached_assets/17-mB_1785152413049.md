# Module B — Import & Logistics + GRA Duty Finance / Customs

**🚦 Flow (lowest level)**

- **1. Capital / factory order raised** — Finance opens a `gates` row `type=capital_order` (evidence: proforma invoice, distributor PO). Blocks any USD-scale commitment above dealer floor until resolved. All rows scoped by `activeDealerId(res)` + `x-dealer-id`; division = CAM/GT on the order.
- **2. Vehicle records created / imported** — `POST /api/vehicles/import` (xlsx via `/import/template`) or per-unit `POST /api/vehicles` with `status=in_transit`, `make/model/trim/year/powertrain`, empty `vin`/`engineNumber` until manifest confirmed. `price` stored USD-scale.
- **3. Freight & landed-cost accrual** — Finance appends CIF components (FOB + freight + insurance) as vehicle `documents[]` / accessory-cost lines. Server never invents CIF; all figures keyed from uploaded shipping docs.
- **4. Dual-currency landed cost** — every stored amount is **USD-scale**; GYD display = `USD × dealer.usdExchangeRate` (~209). Rate snapshotted onto the clearance pack at compute-time so later rate drift does not retro-change a filed duty.
- **5. GRA duty extraction (AI vision, legible-only)** — `POST /api/gra/extract` reads customs/manifest/proforma images and returns **only fields it can legibly read** (make/model/year/CIF-as-printed/engine cc/fuel type). It NEVER computes duty and NEVER fabricates TIN/VIN/CIF. Below `MIN_AGENT_CONFIDENCE` → field dropped, flagged for human key-in. All extracted text wrapped in `guardUntrusted`.
- **6. Server-side deterministic tax compute** — server computes VAT (0% or 14%), import duty, excise/levy strictly from `dealer_taxes` (`kind VAT|duty|excise|levy`, `percent|fixed`, `threshold`, `excludeEv`) against the human-confirmed CIF/GYD base. EV powertrain → `excludeEv` duty lines skipped. No AI arithmetic anywhere in this step.
- **7. Human gate — GRA filing confirm** — a `gates` row `type=gra_filing` holds the computed duty sheet + source docs in `evidence[]`. Finance/Customs reviews line-by-line, corrects any mis-read field, then `POST /api/gates/:id/resolve`. Only a resolved gate unlocks the filing.
- **8. File to GRA** — `POST /api/gra/filings` persists the confirmed, server-computed filing (immutable snapshot: CIF, exchangeRate, per-tax lines, EV flag, filedBy, filedAt). `timeline_events` (domain=finance) + `audit-logs` written, dealer-scoped.
- **9. Clearance pack assembled** — duty sheet + proforma + manifest + bill of lading + GRA filing reference bundled as polymorphic `documents` against the vehicle; generates a printable clearance/landed-cost PDF.
- **10. Registration & plates (3rd-party status)** — registration handled by external agency; tracked only as a `status` field on the delivery step (`registration`) + `vehicles.registration` validated `^[A-Z]{3}[0-9]{1,4}$`. No live GRA/agency integration — manual status transitions.
- **11. Delivery-readiness handoff** — once duty filed + registration status=complete, vehicle `status` flips `in_transit → available`; the linked `deliveries` 9-step (`sales_order→pdi_checklist→registration→insurance→invoice→…`) can advance its `registration`/`insurance` steps. VIN/engineNumber must be present (17 chars) before `available`.

**⚙️ Agents in play**

- **GRA vision extract** (claude-sonnet-4-6) → **trigger:** `POST /api/gra/extract` on customs/manifest/proforma image → **grounded inputs:** only the uploaded document pixels; dealer context for scoping → **output:** `fields{}` of **legibly-read** values + per-field `confidence`; **explicitly forbidden** from computing duty or inventing TIN/VIN/CIF — missing/illegible ⇒ field omitted, never guessed → **HITL:** mandatory `gra_filing` gate; below `MIN_AGENT_CONFIDENCE` field routed to human key-in. Kill-switch `isAgentEnabled`; every call `recordAgentRun` (agent_runs: runType, input/outputSummary, confidence, latency); PII-minimized; output wrapped in `guardUntrusted` before any downstream use.
- **A5 Doc pre-fill** (vision, allowlist `PREFILL_FIELDS`) — may pre-populate benign clearance-doc metadata only; HITL via `/documents/extraction/review`. No tax fields.
- **Deterministic tax engine (NOT an LLM)** — server module computes all duty/VAT/excise from `dealer_taxes`; declared as computation, not an agent, precisely so no AI touches money math. Idempotent compute; result diffed against any client-supplied `taxLines[]` → 422 on mismatch.

**🧠 AI for the persona**

- **Read, don't reckon:** vision extracts what the Customs officer can already read — CIF as printed, engine cc, fuel type, model year — to save keystrokes, never to derive taxable value.
- **Confidence-gated:** any field under `MIN_AGENT_CONFIDENCE` shows blank + "confirm" prompt to Finance, never a low-trust auto-fill.
- **Guyana-correct:** this module fixes the prior Ghana defect — GRA = **Guyana Revenue Authority**, currency GYD, VAT bands 0%/14%, import duty + EV duty exclusions, all sourced from `dealer_taxes`.
- **No fabrication guarantee:** TIN, VIN, CIF, and duty are never model-generated; TIN/VIN come from human-keyed source docs, CIF is human-confirmed, duty is server-computed.
- **Untrusted-text hygiene:** extracted OCR strings pass through `guardUntrusted` so a malicious document cannot inject instructions into the filing or concierge context.

**🔑 Key fields · validations · SLA**

- **Money:** all amounts USD-scale; GYD = `USD × dealer.usdExchangeRate`; the rate is snapshotted onto each `gra_filing` so later rate changes never mutate a filed duty.
- **VIN / engineNumber:** exactly 17 chars; required before vehicle leaves `in_transit`; enforced 422 on write.
- **registration:** `^[A-Z]{3}[0-9]{1,4}$`; 3rd-party status field only (no live agency link).
- **dealer_taxes:** `kind VAT|duty|excise|levy`, `percent|fixed`, `threshold` (duty applies above CIF threshold), `excludeEv` (skipped when `powertrain`=EV).
- **gates:** `type=gra_filing` and `type=capital_order` both block progression until resolved; `evidence[]` holds source docs + computed sheet; `resolution` immutable after resolve.
- **Dates:** filedAt in America/Guyana (GMT-4).
- **Scoping:** extract, filings, gates, audit-logs, and clearance-doc storage ACL are ALL dealer-scoped by `activeDealerId(res)` + `x-dealer-id`.
- **SLA:** extract fire p95 < 8s; duty recompute synchronous < 300ms; `gra_filing` gate target resolution ≤ 1 business day before vehicle delivery-readiness.
- **Idempotency:** `POST /api/gra/filings` keyed via `idempotency_keys` to prevent duplicate filings on retry.

| Registration status stuck (3rd-party delay) | delivery `registration` step incomplete | `advance` returns **422** `{unmet:[registration]}`; vehicle held `in_transit`/`reserved` | Delivery coord | Yes |
| Duplicate filing on retry | `idempotency_keys` hit | returns original filing, no double-file | Server | No |
| VIN </> 17 chars from imported xlsx | schema validation on import | row rejected into `errors[]`; unit stays without VIN, cannot go `available` | Inventory | Yes |
| Cross-dealer document access attempt | storage ACL dealer-scope check | 403; object-storage ACL denies non-owning dealer | Server/ACL | No |

| Threshold-boundary duty (CIF at duty threshold) | deterministic `threshold` comparison | server applies documented boundary rule; sheet shows threshold + basis | Tax engine | No |

**📄 Documents & PDF format**

- **GRA Duty Sheet PDF** (pdfkit) — header: dealer + division (CAM/GT), filing reference, filedAt (America/Guyana), `usdExchangeRate` snapshot. Body: per-unit make/model/year/VIN/engine, CIF (USD + GYD), per-tax lines (VAT 0/14%, import duty, excise/levy) each with basis + rate + amount, EV exclusion note where applicable, computed total duty (USD + GYD). Footer: "Server-computed from dealer_taxes; AI-extracted fields human-confirmed" provenance line + gate resolver + filedBy.
- **Clearance Pack** — polymorphic `documents` bundle against the vehicle: proforma/distributor PO, bill of lading, customs manifest, GRA filing reference, duty sheet PDF, landed-cost summary. Served via presigned GCS URL, dealer-scoped ACL.
- **Landed-cost summary** — FOB + freight + insurance = CIF, + duty/VAT/excise = total landed (USD-scale, GYD display), feeding vehicle cost basis.
- **Registration/plate record** — stored as status field + `vehicles.registration` (regex-validated); no generated cert (3rd-party issues actual plate).
- All PDFs list source-document IDs so every figure is traceable to a human-verified input — no fabricated values.
