# Layer 11 — Service: Scheduled Service Advisor · Manager · Technician

**🚦 Flow (step-by-step, lowest level)**

- **1. Cadence reminder fires.** `POST /api/service-orders/remind` (cron-triggered lazy-eval) scans `coverage_plans` (AMC/warranty due dates) + `assets.deliveredAt` + last `service_orders.scheduledDate` per asset, all filtered by `activeDealerId(res)` + `x-dealer-id`. Emits an OUTBOX row per due asset via `email_logs` (email + WhatsApp), **dedupeKey = `svc-remind:{assetId}:{dueMonth}`** so a reminder never double-sends. Agent brief (A7 Outreach) may draft copy — never auto-sends.
- **2. Validate contact + vehicle identity.** On `POST /api/service-orders` the server re-validates `customers.email` (RFC + MX-soft), `vehicles.vin` = 17 chars, `vehicles.registration` matches `^[A-Z]{3}[0-9]{1,4}$`, and that the vehicle is an `assets` row owned by this dealer/customer. Mismatch → **422** before any Case is opened.
- **3. Open the Case (first-class `service_orders`).** Creates a `service_orders` row (`type` maintenance|repair|recall|comeback, `status=open`, `scheduledDate`, `complaint` [wrapped in `guardUntrusted`], `odometer`). Emits `timeline_events` on the asset.
- **4. Manager review gate.** Cases flagged capital/recall/goodwill raise a `gates` row (`type=stage_advance` for readiness, manager-owned). Advance is the ONE primary CTA **"Advance to Scheduled"**; `POST /api/service-orders/:id/advance` returns **422 {unmet:[]}** against versioned `stage_checklists` if gates unmet.
- **5. Open the Work Order (`job_cards`).** `POST /api/job-cards` — enforce **exactly one active (open|in_progress) job_card per asset**; second attempt → 409. Seeds `checklist[]` from `service_orders.jobs[]`, sets `laborHours=0`, `status=open`.
- **6. Appointment.** Assign technician (`/service-technicians` availability), bay, duration; write to `bookings`-style slot + `tasks`/`notifications`. **24h-before reminder** queued to outbox (dedupeKey `appt-remind:{jobCardId}`).
- **7. Intake checklist.** Technician records odometer-in, fuel, loaner issued, damage walk-around (photos → `customer_documents`/`documents`), customer signature via `signatureData`-style capture. PDI-style items stored in `job_cards.checklist[]`.
- **8. Parts.** `POST /api/job-cards/:id/parts` issues `job_card_parts` against `parts.stock`; short stock → **backorder** (create `part_purchases` to `suppliers`) or **supersession** (linked SKU); Case moves to **on-hold** if awaiting parts.
- **9. Quote → approve.** `POST /api/job-cards/:id` computes labor+parts+tax (GRA VAT via `dealer_taxes`, server-side deterministic). Customer approval (WhatsApp/email link) or `gates`. Pay type set: **warranty | customer | goodwill | rectify**.
- **10. Repair → outtake.** `status=in_progress→completed`, actual `laborHours` logged, QC outtake checklist, unused parts **returned to stock** (`job_card_parts` return).
- **11. Service invoice → pickup.** `POST /api/job-cards/:id/invoice` → `service_invoices`; `/payments` (idempotent) recompute + `receipts`. Pickup signature, loaner return, sublet reconciliation, then Case `status=closed` and appended to **Service History** (`assets` timeline).

**⚙️ Agents in play**

- **A7 Outreach composer** → trigger: service reminder due / on-hold parts arrival → grounded inputs: `service_orders`, `coverage_plans`, `assets.deliveredAt`, last `service_invoices` (dealer-scoped) → output `{headline,riskLevel,actions[],draftMessage}` via `GET /leads/:id/agent-brief` equivalent → **HITL: YES**, human "Approve & Send" through `/outreach` or `/whatsapp`; never auto-sends. Respects `MIN_AGENT_CONFIDENCE` (below floor → route to advisor, no draft surfaced as ready).
- **A6 Call sentiment** → trigger: advisor logs a `call_logs`/comm note on the Case (fire-and-forget) + manual `POST /leads/:id/calls/:cid/suggest-sentiment` → input: guarded call transcript/note → output `{sentiment,confidence}` on `call_logs` → autonomous-write, therefore **declared in `agents`, audited in `agent_runs`, kill-switchable** (isAgentEnabled). HITL: advisor can override.
- **A2 Round-robin (deterministic, not LLM)** → trigger: Case needs an advisor → picks by `dealer_users.lastLeadAssignedAt` within `divisionId` → output: `serviceAdvisorUserId`. HITL: manager reassign.
- **A3 Quote/Code (deterministic tax engine)** → trigger: job_card quote build → inputs: `job_card_parts`, `laborHours`, `dealer_taxes` (GRA VAT 0%/14%, duty, EV exclusions) → output: pdfkit service quote PDF + `taxLines[]`. **No LLM; server computes tax deterministically.**
- **A5 Document pre-fill (vision, HITL)** → trigger: uploaded warranty claim / recall notice → allowlist `PREFILL_FIELDS`, `extractionStatus:'proposed'` → confirm via `/documents/extraction/review`. **Never invents VIN/coverage.**

**🧠 AI for the persona**

- **Service Advisor:** A7 draft reminder + "next-service" upsell suggestion grounded in real coverage/history; sentiment flag on inbound WhatsApp complaint (guarded) to prioritize the queue.
- **Manager:** pipeline/readiness surface for capital-repair & recall Cases with confidence and unmet-gate list before approving **"Advance"**; disambiguated as **Readiness check** (stage), **Approvals** (manager gate), **Approve/Override run** (AI).
- **Technician:** A5 pre-fill of warranty claim fields (proposed, human-confirmed); supersession suggestion when SKU out of stock (validated against `parts`, no fabricated SKUs).

**🔑 Key fields · validations · SLA**

- **Identity validations:** `vin`/`engineNumber` = 17 chars; `registration` `^[A-Z]{3}[0-9]{1,4}$`; `email` RFC; `odometer` must be ≥ last recorded odometer for the asset (non-decreasing) else 422.
- **Case fields:** `service_orders`.{`type`,`status` open→in_progress→completed/closed/on-hold,`scheduledDate`,`complaint`(guarded),`odometer`,`jobs[]`,`payType` warranty|customer|goodwill|rectify,`serviceAdvisorUserId`}.
- **Work order:** `job_cards`.{`checklist[]`,`laborHours`,`status`} — invariant: **one active job_card per asset**.
- **Money:** stored USD-scale; GYD display = amount × `dealer.usdExchangeRate`; tax from `dealer_taxes` (VAT/duty/excise, percent|fixed, threshold, `excludeEv`); rectify/goodwill lines = 0 to customer.
- **SLA timers:** cadence reminder T-14/T-7 days pre-`scheduledDate`; appointment reminder **24h before**; on-hold parts escalation to manager if backorder ETA > 5 business days; quote-approval SLA 48h then Case auto-parks (not cancels).
- **Config touched:** versioned `stage_checklists` (service variant gates), `dealer_taxes`, `coverage_plans`. Dates in America/Guyana GMT-4.
- **Guardrails:** every query `activeDealerId`-scoped incl. audit-logs & object-storage per-object ACL; all untrusted text (complaint, inbound WhatsApp/email, uploaded docs) via `guardUntrusted`; money mutations use `idempotency_keys`.

**🔀 Edge-of-edge cases → handling**

| Scenario | Detection | Handling | Owner | HITL? |
| --- | --- | --- | --- | --- |
| Two advisors open a Work Order for same asset | Unique partial index on `job_cards(assetId) WHERE status IN(open,in_progress)` | Second write → 409 `active_job_card_exists`; UI links to the live card | Service Advisor | No |
| Reminder double-send on cron re-run | `email_logs.dedupeKey = svc-remind:{assetId}:{dueMonth}` collision | Outbox dedupe drops duplicate; logged as `skipped` | Email worker | No |
| WhatsApp opt-out / STOP inbound | Guarded inbound classified opt-out; `whatsapp_conversations` flag | Suppress channel, fall back to email; if both suppressed → `tasks` to call | Advisor | Yes (call) |
| WhatsApp/email failed delivery (bounce) | Provider webhook / SMTP bounce → `email_logs` retry/backoff exhausted | Mark undeliverable, create follow-up `task`, try alt channel | Email worker | Yes |
| Part short stock at issue | `parts.stock < qty` | Create `part_purchases` (backorder) OR offer supersession SKU (validated); Case → on-hold | Parts | Yes (approve super.) |
| Superseded/discontinued SKU | Part flagged superseded, linked replacement | Suggest linked SKU only; never fabricate part number | Parts / A5 | Yes |
| Unused parts left on completed job | Outtake QC checklist mismatch (issued > consumed) | `job_card_parts` return-to-stock; invoice recomputes | Technician | No |
| Odometer entered lower than history | Non-decreasing check vs last `service_orders.odometer` | 422; require correction or flag as replacement cluster note | Advisor | Yes |
| Warranty expired mid-repair | `coverage_plans.validUntil < today` | Recompute payType customer; re-quote & re-approve before proceeding | Advisor | Yes |
| Recall Case | `type=recall` | payType warranty, 0 to customer; manufacturer campaign ref required; manager gate | Manager | Yes |
| Comeback (same complaint <30d) | Prior closed Case same VIN + complaint window | Link parent Case; payType rectify (0); root-cause note; no re-diagnosis charge | Advisor / Manager | Yes |
| Goodwill authorization | payType=goodwill selected | Raise `gates` (manager); amount waived logged in `timeline_events` | Manager | Yes |
| Sublet work (external vendor) | Line flagged sublet on job_card | Track vendor cost via `part_purchases`/supplier; markup per config; reconcile on invoice | Advisor | No |
| Loaner vehicle issued | Intake checklist loaner flag → `vehicles.status=service/hold` | Soft-lock loaner (`holdUntil`); block on non-return at pickup | Advisor | Yes |
| Soft-lock (loaner hold) expiry | Lazy check `holdUntil < now` | Release hold, alert advisor if loaner still out | System | Yes |
| Payment bounced / cheque reversed | Reversal payment row; invoice recompute | Invoice back to `partially_paid`; block Service-History close; dunning `task` | Cashier | Yes |
| Duplicate payment submit | Same `idempotencyKey` | Replay returns original `receiptId` (200), no double-charge | System | No |
| Concurrent quote edits | Row version / updatedAt mismatch on PATCH | 409 optimistic-lock; reload & merge | Advisor | Yes |
| Cross-tenant asset access | Asset's `dealerId ≠ activeDealerId` | 404 (not 403) — never leak existence; audit-log the attempt (dealer-scoped) | System | No |
| AI sentiment below confidence floor | `confidence < MIN_AGENT_CONFIDENCE` | Do not auto-tag; route to advisor for manual sentiment | A6 / Advisor | Yes |
| Agent kill-switch paused | `agents.status=paused` | Skip A6/A7 silently; log skipped `agent_runs`; manual path unaffected | System | No |
| Uploaded warranty doc with injected instructions | `guardUntrusted` on extracted text | Neutralized; A5 proposes allowlisted fields only, human confirms | Technician | Yes |
| Advance attempted with unmet gate | `stage_checklists` eval | 422 `{unmet:[]}`; single "Advance" CTA stays disabled with reasons | Advisor / Manager | Yes |

**📄 Documents & PDF format**

- **Service Repair Order / Estimate PDF** (generator: `pdfkit`, deterministic A3 engine; channel: WhatsApp + email outbox for approval). Layout — **Header:** dealer logo, division (CAM/GT), Case/RO number, date (GMT-4), advisor. **Vehicle block:** make/model/year, VIN, registration, odometer-in. **Customer block:** name, contact. **Line items table columns:** Op/Description · Type(labor|part|sublet) · Qty · Unit(GYD) · Amount(GYD) · PayType(warranty/customer/goodwill/rectify). **Totals:** Labor subtotal · Parts subtotal · Sublet · `taxLines[]` (GRA VAT 0%/14%, duty) · Grand total GYD (= USD × usdExchangeRate). **Footer:** validUntil, customer approval signature line, disclaimer.
- **Intake / walk-around sheet** (checklist + `signatureData` capture; stored to `documents`/object storage with per-object ACL). Fields: fuel level, damage map, loaner issued Y/N, customer authorization signature.
- **Service Invoice PDF** (generator: `pdfkit`; entity `service_invoices`; channel: email outbox + pickup print). Layout mirrors estimate with `invoiceNumber`, status(issued|partially_paid|paid), payments applied, receipt reference, outstanding balance. Only customer-payable lines charged; warranty/goodwill/rectify shown at 0.
- **Payment receipt** (`receipts`): receipt no, method (cash|card|bank_transfer|cheque|mobile_money|financing), amount GYD, invoice ref, idempotency-safe.
- **Service History record** (appended to `assets` timeline, no PDF): Case number, date, odometer, jobs, parts SKUs, payType, total — feeds next cadence reminder and resale value.
