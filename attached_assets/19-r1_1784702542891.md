# Reference R1 — Data Model (all ~57 tables)

Authoritative schema reference for the **AURA** automotive DMS (Guyana; dealers `CAM Motors`, `GT Automotive`). Storage is Drizzle ORM over PostgreSQL, contract-first from OpenAPI. Conventions applied throughout:

- **Tenancy:** `dealers` is the tenant root. **Every** other business table is dealer-scoped and **every** query filters on the resolved `activeDealerId(res)` reconciled against the `x-dealer-id` header — including concierge grounding reads, `audit_logs`, and object-storage ACL checks. A table is marked **Scope = dealerId** when it carries a direct `dealerId` FK, or **Scope = via FK** when scoped transitively through its parent (join always re-asserts `dealerId`).
- **Money:** stored at `USD` scale (integer/decimal USD); GYD display = `USD × dealer.usdExchangeRate` (~209). Never persist GYD.
- **Dates:** timestamptz; business rendering in `America/Guyana` (GMT-4).
- **Identifiers:** `vin` & `engineNumber` are 17 chars; `registration` matches `^[A-Z]{3}[0-9]{1,4}$`.
- **Standard columns** on most tables (omitted from field lists below unless load-bearing): `id` (uuid PK), `dealerId` (FK→`dealers.id`), `createdAt`, `updatedAt`, `createdByUserId`.

## Cross-cutting integrity rules

- **Every** table above except `users` (global identity) carries or transitively enforces `dealerId`; joins re-assert it to prevent cross-tenant leakage.
- All monetary columns (`price`, `vehiclePrice`, `otdPrice`, `total`, `amount`, `bookingAmount`, `lifetimeValue`, `cost`, etc.) are stored at **USD scale**; GYD is a display projection via `dealers.usdExchangeRate`.
- Vehicle lifecycle status is single-sourced on `vehicles.status`; `deals` (commit/VIN-lock), `bookings`, and `deliveries` transition it — no duplicate status columns.
- Every AI-touched table (`customer_personas`, `documents`, `call_logs`, `quotes` tax, GRA extraction) records provenance in `agent_runs` and defers below-confidence output to a human via `gates` or a HITL review endpoint.
