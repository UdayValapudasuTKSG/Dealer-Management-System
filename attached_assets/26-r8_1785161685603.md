# Reference R8 — Document & PDF Template Layouts

All AURA documents are rendered server-side with `pdfkit` (see `server/pdf/quote-pdf.ts` and the delivery-invoice renderer). No client-side PDF generation exists. Every document is **dealer-scoped**: the header block, logo, currency conversion rate, terms, and tax lines are all resolved from the `dealers` row bound to `activeDealerId(res)` / `x-dealer-id` — never a global default. Money is stored USD-scale and displayed as GYD via `USD × dealer.usdExchangeRate` (~209); both figures are printed. Dates render in `America/Guyana` (GMT-4). Tax lines are always computed **deterministically on the server** from `dealer_taxes` (agent A3 for sales code/quote; never AI-invented amounts).

## R8.0 — Shared Rendering Contract

| Concern | Rule |
| --- | --- |
| Generator | `pdfkit` streaming to buffer → `storage/objects` (GCS via Replit sidecar, ACL-scoped to dealer) → presigned URL, OR streamed inline on the `*.pdf` endpoint. |
| Dealer resolution | Header/logo/terms/footer from `dealers` (name, division CAM\|GT, address, TIN placeholder, logo asset). Division badge from `divisions`. |
| Currency | Every money value printed twice: **USD** (stored) and **GYD** = `round(USD × dealer.usdExchangeRate)`. Rate printed in footer as of issue date. |
| Tax source | `dealer_taxes` rows: `kind` ∈ VAT\|duty\|excise\|levy, `percent`\|`fixed`, `threshold`, `excludeEv`. Applied in row order; EV vehicles skip rows with `excludeEv=true`. |
| Vehicle identity | VIN (17), `engineNumber` (17), `registration` (`^[A-Z]{3}[0-9]{1,4}$`), make/model/trim/year from `vehicles`. |
| Untrusted text | Any customer-supplied note/complaint/free-text merged into a PDF is passed through `guardUntrusted` before rendering. |
| Quotation vs Invoice | **Identical layout skeleton**; only the document title, the number field (`quoteNumber` vs `invoiceNumber`), and the footer (validity vs receipt/payment) differ. |

## R8.1 — Sales Code / Quotation (GT format)

**Generator:** `quote-pdf.ts` (pdfkit), values from agent A3 (deterministic tax + pdfkit). **Source tables:** `quotes` (versioned: `quoteNumber`, `taxLines[]`, `total`, `validUntil`, `status` current|superseded, `sentVia`), `leads`, `vehicles`. **Endpoints:** `POST /leads/:id/quote`, `GET /leads/:id/quote.pdf`, `GET /leads/:id/quotes/:id/pdf`. **Delivery:** `POST /leads/:id/quotes/:id/send` → email outbox (`email_logs`) or WhatsApp outbox; `sentVia` recorded.

| Zone | Contents |
| --- | --- |
| Header | Dealer logo + name (CAM Motors / GT Automotive), division badge, dealer address; doc title `QUOTATION`; `quoteNumber`; issue date (Guyana TZ); version tag (v1, v2… — superseded versions watermarked). |
| Party block | Customer: name, `accountType` person\|business, contact (from `contacts`), lead ref. Vehicle: make/model/trim/year, VIN, `registration` (if allocated), `selectedModel` / `interestedVehicleId`, powertrain. |
| Line items | Columns: *Description* \| *Qty* \| *Unit Price (USD)* \| *Unit Price (GYD)* \| *Line Total (USD/GYD)*. Rows: vehicle base `price`, accessories[], less discount, less `tradeInValue` (if quoted with appraisal). |
| Tax lines | One row per applicable `dealer_taxes` entry: VAT (0/14%), import duty, excise/levy as configured. EV skips `excludeEv` rows. Each shows rate + USD + GYD. |
| Totals block | Subtotal, discount, taxable base, total tax, **Grand Total in GYD (bold) + USD**. Deposit / reservation fee line if applicable. |
| Footer | `validUntil` date, terms & conditions, exchange rate used, prepared-by advisor (`ownerUserId`/`assignedTo`). No receipt number (unpaid document). |

## R8.2 — Reservation Invoice

**Generator:** pdfkit invoice renderer. **Source:** `bookings` (`vehicleId`, `bookingAmount`, `amountPaid`, `paymentStatus`, `expiresAt`), `invoices` (`invoiceNumber`, status), `payments` (idempotent), `receipts`. Also driven by `leads.reservationFeePaid`. **Delivery:** email/WhatsApp outbox after payment recorded via idempotent `POST /payments`. **Layout = Invoice skeleton**, title `RESERVATION INVOICE`.

| Zone | Contents |
| --- | --- |
| Header | Dealer/logo/division; title `RESERVATION INVOICE`; `invoiceNumber`; issue date. |
| Party block | Customer + reserved vehicle: make/model/year, VIN, `holdUntil`/`holdReason`, vehicle status **reserved**. |
| Line items | Reservation / booking fee (`bookingAmount`) row; USD + GYD. |
| Tax lines | VAT on fee if `dealer_taxes` configures it; otherwise none. |
| Totals block | Fee total GYD + USD; `amountPaid`; balance to full deal (informational). `paymentStatus`. |
| Footer | Reservation `expiresAt` (booking expiry), refund terms, method (cash\|card\|bank_transfer\|cheque\|mobile_money\|financing), **receipt #** from `receipts`, exchange rate. |

## R8.3 — Final Invoice (Vehicle Sale)

**Generator:** pdfkit; issued when `deals.stage=committed` (VIN-lock on commit, auto-creates delivery). **Source:** `deals` (`vehiclePrice`, `discount`, `tradeInValue`, `otdPrice`, `depositPaid`, `salesAdvisorUserId`), `invoices`, `payments`, `receipts`, `outstanding-balances`. **Endpoint:** exposed via delivery step (`/deliveries/:id/invoice.pdf`) as the tax invoice. **Delivery:** email/WhatsApp outbox + attached to delivery pack.

| Zone | Contents |
| --- | --- |
| Header | Dealer/logo/division; title `TAX INVOICE`; `invoiceNumber`; issue date; deal ref. |
| Party block | Customer (person\|business, `parentAccountId` for business), vehicle: make/model/trim/year, **VIN + engineNumber + registration**, powertrain. |
| Line items | *Description \| Qty \| Unit USD \| Unit GYD \| Total*: vehicle price, accessories[], trade-in credit (negative, from linked `appraisals.finalOffer`), discount (gated: >5% triggers `gates` below_floor_price). |
| Tax lines | All applicable `dealer_taxes`: VAT 0/14%, import duty, excise, levy; EV exclusions honored; each with rate + USD + GYD. |
| Totals block | Subtotal, discount, taxable base, per-tax totals, **OTD price (`otdPrice`) in GYD + USD**; deposit paid; balance due / financing portion. |
| Footer | Payment method(s), financing note (`finance_applications.losReference` if applicable), **receipt #**, exchange rate, advisor (`salesAdvisorUserId`), invoice status issued\|partially_paid\|paid\|void. |

## R8.4 — Delivery Handover Form

**Generator:** pdfkit delivery renderer over the 9-step `deliveries.steps` jsonb. **Source:** `deliveries` (`pdiItems[]`, `signatureData`, `feedbackRating`, `feedbackComment`, registration/insurance fields), `assets` (`deliveredAt`, `serviceAdvisorUserId`), `coverage_plans`. **Endpoints:** `POST /deliveries/:id/advance` (steps sales_order→pdi_checklist→registration→insurance→invoice→appointment→delivery→signature→feedback), `GET /deliveries/:id/pdi`, `/delivery-advisors`. **Delivery of doc:** signed copy to email/WhatsApp outbox; feedback captured as first-class Review/CSAT entity.

| Zone | Contents |
| --- | --- |
| Header | Dealer/logo/division; title `VEHICLE DELIVERY & HANDOVER`; delivery ref; `deliveredAt` date. |
| Party block | Customer + delivery advisor (`serviceAdvisorUserId`/`delivery-advisors`); vehicle: make/model/year, **VIN, engineNumber, registration**, odometer at handover. |
| Line items / checklists | PDI checklist table (`pdiItems[]`: item \| pass/fail \| note); registration details; insurance policy fields; linked invoice #; coverage plan (warranty\|amc) terms. |
| Tax lines | None on handover itself (references the Final Invoice for amounts). |
| Totals / acknowledgement | Summary of items delivered (keys, documents[], accessories[]); asset created (`assets.status=active`). |
| Footer | **Customer signature** (`signatureData`) + date; advisor signature; CSAT rating/comment (`feedbackRating`/`feedbackComment`, guardUntrusted); handover terms. |

## R8.5 — Service Quotation

**Generator:** pdfkit. **Source:** `service_orders` (type, complaint, odometer), `job_cards` (`checklist[]`, `laborHours`, `laborRate`), `job_card_parts`, `parts` (sku, cost). **Endpoint:** job-card / service-order estimate; **Delivery:** email/WhatsApp outbox. **Layout = quotation skeleton**, title `SERVICE QUOTATION`.

| Zone | Contents |
| --- | --- |
| Header | Dealer/logo/division; title `SERVICE QUOTATION`; service-order ref; date. |
| Party block | Customer + vehicle from `assets`: make/model/year, VIN, registration, **odometer**; complaint (guardUntrusted); technician. |
| Line items | Two groups — *Labor* (job description \| hours `laborHours` \| rate `laborRate` \| USD/GYD) and *Parts* (sku \| qty \| unit cost \| USD/GYD from `job_card_parts` issue moves). |
| Tax lines | VAT per `dealer_taxes` on labor + parts as configured. |
| Totals block | Labor subtotal, parts subtotal, tax, **Grand Total GYD + USD**. |
| Footer | `validUntil`, authorization terms, exchange rate, advisor. No receipt (unpaid). |

## R8.6 — Service Invoice

**Generator:** pdfkit. **Source:** `service_invoices`, `job_cards` (status completed), `job_card_parts`, `coverage_plans` (warranty|amc offsets), `payments`, `receipts`. **Endpoint:** `/job-cards/:id/invoice`, service-invoices. **Delivery:** email/WhatsApp outbox. **Layout = invoice skeleton**, title `SERVICE INVOICE`.

| Zone | Contents |
| --- | --- |
| Header | Dealer/logo/division; title `SERVICE INVOICE`; `invoiceNumber`; date; job-card ref. |
| Party block | Customer + vehicle (VIN, registration, odometer), technician, coverage plan applied. |
| Line items | Labor rows (final `laborHours`×`laborRate`) + parts rows (returned parts credited via `job_card_parts` return moves); warranty/AMC coverage line as credit. |
| Tax lines | VAT per `dealer_taxes` on net taxable amount. |
| Totals block | Labor total, parts total, coverage credit, tax, **Amount Due GYD + USD**. |
| Footer | Payment method, **receipt #**, status issued\|partially_paid\|paid\|void, exchange rate, terms. |

## R8.7 — GRA Duty Pack (Guyana Revenue Authority)

**GRA = Guyana Revenue Authority** (GYD; VAT 0/14%; import duty; EV duty exclusions) — **not Ghana**. **Generator:** pdfkit assembly of extracted-field summary + computed duty. **Source:** `gra/extract` (AI vision on `documents.extraction` jsonb — **extracts legible fields only**, never invents TIN/VIN/CIF/duty), `dealer_taxes` (server computes duty deterministically), `gates` (type `gra_filing`, evidence[], resolution), `gra/filings`. **Delivery:** generated only after the **gra_filing human gate** confirms figures; then email/outbox + stored in `storage/objects` (dealer-ACL). Enforces `MIN_AGENT_CONFIDENCE` — low-confidence extractions route to the human gate, never auto-file.

| Zone | Contents |
| --- | --- |
| Header | Dealer/logo/division; title `GRA IMPORT DUTY PACK`; filing ref (`gra/filings`); date (Guyana TZ). |
| Party / entity block | Dealer TIN (from dealer config — never invented), importer/customer; vehicle: make/model/year, **VIN, engineNumber** (extracted + human-confirmed), CIF value. |
| Extracted fields | AI-extracted legible fields (bill of lading, invoice value, CIF, cc/powertrain) each tagged with source doc + confidence; low-confidence flagged for gate review. |
| Tax / duty lines | **Server-computed** from `dealer_taxes`: import duty %, VAT 0/14%, excise/levy; EV rows skipped where `excludeEv=true`. Each shows rate + base + GYD. |
| Totals block | CIF (GYD + USD), total duty, VAT, **Total Payable to GRA in GYD** (+ USD reference). |
| Footer | Gate resolution (`gates.resolution`) + confirming user, evidence[] doc references, exchange rate, declaration that figures were server-computed and human-confirmed. |
