# §0 — Normative Contract Single Source of Truth

> This section is **authoritative**. Where any other section appears to differ, §0 governs — it guarantees the spec is internally consistent. Anchors are lowercase (`#r1`…`#r10`).

## NC-1 · HTTP status codes

| Code | Meaning (canonical) |
| --- | --- |
| `401` | No/invalid session. A missing `x-dealer-id` is never a 401 by itself. |
| `403` | Authenticated but not permitted — RBAC denial **or** `x-dealer-id` not in caller memberships. |
| `404` | Resource id not found **within the active dealer scope** (how cross-tenant rows are hidden). **Never 403 for a foreign row.** Also: not-entitled module/agent. |
| `409` | Idempotency in-flight/duplicate, or write conflict. |
| `422` | Validation; unmet gate `{unmet:[]}`; idempotency `key_reuse_mismatch`. |
| `423` | Tenant suspended — writes blocked, reads allowed. |
| `429` | Rate limited (+ `Retry-After`). |
| `202` | Accepted async (enquiries, remind, export, outreach). |
| `400` | Malformed, or unresolvable dealer on a mutation (`dealer_required`). |

**NC-14 missing header:** data-plane GET → default-dealer resolution (lastActive → sole membership → else 200 picker payload); mutation with no resolvable dealer → 400.

## NC-6 · Agents

**Autonomous LLM writers** (internal-only, audited, kill-switchable): A1 `intake_dedup`, A6 `call_sentiment`, A16 `case_classifier`. **Deterministic system actions** (code, not LLM, not kill-switchable): A2 round_robin, A3 quote_tax, A11 vin_allocation. **HITL/advisory**: A5 doc_prefill, A7 outreach (Approve&Send), A10 test_drive_availability, A15 pipeline_suggestions, sentiment_digest, persona_recommend, concierge (nav-only), gra_extract. Kill-switch `isAgentEnabled(semanticKey)` = platform governance capability (NC-13). No "A1–A27" range.

## NC-7…14 · Other invariants

- **NC-7 Idempotency:** Idempotency-Key on mutations; replay→stored, in-flight→409, key-reuse-diff-body→422.
- **NC-8 First-class entities:** `test_drives`, `service_cases`, `reviews` as real tables (built app modelled as fields).
- **NC-9 Entitlements:** pipeline gate after RBAC; not-entitled → 404; INV-ENT-1 server-side.
- **NC-10 Impersonation:** read-only default, ≤60m, audited; writes need elevation; money/gate/customer-send hard-blocked.
- **NC-11 Multi-step:** saga + durable markers + compensation; never hold a DB txn across GCS/SMTP/LOS.
- **NC-12 Honesty:** "foolproof" = application-logic + tenant/money/AI invariants (V3). DR, encryption-at-rest, HA, tracing, broker = PENDING-INFRA (pre-GA blockers), not claimed. r9 = built-app defects+mandate; V4 = spec/infra open items.
- **NC-13 Kill-switch governance:** platform-reserved; not grantable via `/admin/roles`; not `settings:admin`.
