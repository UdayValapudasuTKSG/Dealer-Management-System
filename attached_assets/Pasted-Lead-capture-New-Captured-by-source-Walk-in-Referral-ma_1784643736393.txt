10 · Service — Scheduled (feature-flagged)
🤖 Introduction call within 5 business days of delivery; SA explains the cadence/milestones; sets a follow-up reminder.
🤖 Milestone approaching → reminder. SA validates customer info (Email / VIN / Registration) → creates a Case (Types of Service, Concern, Cause, Correction, Current Mileage, Requested Completion Date, Is-Off-Road). ✋ SA confirms with customer.
🤖 Notify Service Manager → 🅱️ Manager reviews Case, consults Technician for scope, records notes, instructs SA to open a Work Order.
🤖 SA notified (email + in-app) → reviews Manager's notes → updates notes → CLOSES the Case → OPENS a Work Order.
SA books appointment (calendar: Customer + Technician + Duration); 🤖 24h drop-off reminder. Customer drops off → SA completes the intake checklist, uploads to WO. SA tells technician (offline). Technician inspects → parts needed?
Parts NOT needed: add Work Order Line Items → prepare quotation → ✋ customer approves → repair → schedule pickup → outtake list → invoice → payment → customer collects → outtake list + receipt reference added to WO.
Parts needed: SA contacts Parts Advisor; WO On Hold until part/technician available → then the same WOLI → quote → approve → repair → outtake → invoice → pickup.
🚦 Only one active Work Order per asset. WO statuses: New → Pending Manager Review → In Progress → On Hold → Completed → Invoice → Closed. Pay Type: Warranty / Customer Pay / Rectify / Goodwill. Generate Quotation / Generate Invoice produce the same PDF (Subtotal + VAT + Total) with only the heading differing. Entry added to Service History; Warranty/Claim tracked where applicable.
11 · Service — Unscheduled
Customer contacts SA → SA validates info → creates Case → triages on the call: resolved → close Case with notes; not resolved → same Manager review → Work Order path as scheduled.
