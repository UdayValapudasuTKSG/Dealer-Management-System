The one utility everything depends on — src/lib/utils.ts :

import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"
export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)) }

Notable upstream pieces worth knowing you have:
sonner — toast notifications (use instead of building your own).
command (cmdk) — ⌘K command palette.
chart + recharts — themed charts using the monochrome --chart-* ramp.
resizable (react-resizable-panels), drawer / sheet (vaul), sidebar .
form = react-hook-form + zod resolver.

B. Custom design primitives (reproduce verbatim — this is the
identity)
All are tiny, presentational, and use only cn() + Tailwind. Domain words removed.
SectionLabel — the ubiquitous eyebrow

export function SectionLabel({ children, className }: {
children: React.ReactNode; className?: string;
}) {
return (
<div className={cn(
"text-[10px] font-medium uppercase tracking-[0.18em] text-zinc-500",
className,
)}>{children}</div>
);
}

BigStat — the serif hero number

export function BigStat({ value, label, delta, className }: {
value: string; label?: string;
delta?: { value: string; positive?: boolean }; className?: string;
}) {
return (
<div className={cn("flex flex-col gap-1", className)}>
{label && (
<div className="text-[10px] font-medium uppercase tracking-[0.18em] text-zinc-500">
{label}
</div>
)}
<div className="flex items-baseline gap-3">
<div className="font-serif text-5xl font-medium tracking-tight tabular-nums text-zinc-900">
{value}
</div>
{delta && (
<div className={cn("text-xs font-medium tabular-nums",
delta.positive ? "text-emerald-700" : "text-rose-700")}>
{delta.value}
</div>
)}
</div>
</div>
);
}

ConfidenceBar — labeled thin progress (great for AI confidence/scores)

export function ConfidenceBar({ value, className }: { value: number; className?: string }) {
const v = Math.max(0, Math.min(100, value));
return (
<div className={cn("w-full", className)}>
<div className="flex items-center justify-between mb-1">
<span className="text-[10px] font-medium uppercase tracking-[0.18em] text-zinc-500">
AI confidence
</span>
<span className="text-[11px] font-medium tabular-nums text-zinc-900">{v}%</span>
</div>
<div className="h-1 w-full rounded-full bg-zinc-100 overflow-hidden">
<div className="h-full bg-zinc-900 rounded-full transition-all duration-500"
style={{ width: `${v}%` }} />
</div>
</div>
);
}

StatusChip — the dot+label pill (generic version of "StageChip")

const DOT: Record<string, string> = {
a: "bg-amber-500", b: "bg-sky-500", c: "bg-violet-500",
d: "bg-indigo-500", done: "bg-emerald-500", idle: "bg-zinc-400",
};
export function StatusChip({ status, label, className }: {
status: string; label: string; className?: string;
}) {
return (
<span className={cn(
"inline-flex items-center gap-1.5 rounded-full border border-black/10 bg-zinc-50",
"px-2.5 py-0.5 text-[11px] font-medium text-zinc-700", className,
)}>
<span className={cn("h-1.5 w-1.5 rounded-full", DOT[status] ?? "bg-zinc-400")} />
{label}
</span>
);
}

SeverityPill — colored tier pill (generic "BadFaithPill")

type Sev = "LOW" | "MED" | "HIGH";
const STYLE: Record<Sev, string> = {
LOW: "bg-emerald-50 text-emerald-700 border-emerald-200",
MED: "bg-amber-50 text-amber-800 border-amber-200",
HIGH: "bg-rose-50 text-rose-700 border-rose-200",
};
export function SeverityPill({ level, label }: { level: Sev; label?: string }) {
return (
<span className={cn(
"inline-flex items-center gap-1.5 rounded-full border px-2.5 py-0.5 text-[11px] font-medium",
STYLE[level],
)}>{label ?? level}</span>
);
}

Component rules carried over from the source
Default to presentational; data-fetching lives in container/page layer.
Promote, don't duplicate: first reuse → feature folder, second → shared domain/ .
Component file > ~200 lines → split. No prop drilling > 2 levels.
Every interactive element gets a data-testid .
Icons are lucide-react , sized h-3 w-3 … h-3.5 w-3.5 , shrink-0 .
