# How it works technically

## Step 1: Customer sends a message

For example:

```
Hi
```

Meta sends a webhook to your backend.

```json
{
  "from":"919876543210",
  "text":{
      "body":"Hi"
  }
}
```

---

## Step 2: Your backend manages the conversation

Store a conversation state.

```text
Customer

Phone

Current Step

Collected Data
```

Example:

```text
919876543210

ASK_NAME

{}
```

---

## Step 3: Ask for the customer's name

Send a message:

```
Welcome to ABC Motors.

May I know your name?
```

Customer replies:

```
John
```

Update the state:

```text
ASK_MOBILE

{
  "name":"John"
}
```

---

## Step 4: Ask for the mobile number

```
Please enter your mobile number.
```

Customer replies:

```
9876543210
```

Store it.

---

## Step 5: Ask for the interested model

Instead of free text, you can send an **interactive list** or **reply buttons**.

Example:

```
Select the vehicle you're interested in:

• Creta
• Venue
• Verna
• Tucson
• Other
```

The customer taps one option.

---

## Step 6: Create the lead

Once all required fields are collected:

```json
{
    "name":"John",
    "mobile":"9876543210",
    "vehicle":"Creta",
    "source":"WhatsApp"
}
```

Your backend calls your DMS API:

```http
POST /api/leads
```

The lead is now created automatically.

# Can Meta ask questions automatically?

**Yes**, but **Meta itself does not maintain the conversation logic**.

Meta provides the messaging channel:

* Send messages
* Receive replies
* Interactive buttons
* Interactive lists
* Templates
* Media
* Webhooks

Your application is responsible for deciding:

* What question to ask next
* Validating responses
* Storing answers
* Creating the lead

Think of Meta as the "transport layer" and your backend as the "conversation engine."

# AI-enhanced version (optional)

Instead of fixed steps, you can let an AI interpret the conversation.

Customer:

> I'm Rahul, my number is 9876543210, and I'm interested in the Hyundai Creta.

The AI extracts:

```json
{
  "name":"Rahul",
  "mobile":"9876543210",
  "model":"Hyundai Creta"
}
```

If something is missing, the AI asks only for the missing information:

> Thanks, Rahul! Which dealership location would you prefer?

This feels much more natural than a rigid form.
