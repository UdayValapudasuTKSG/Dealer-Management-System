# Layer 0 — Cross-cutting All personas

**🚦 Flow (lowest level)**

- **Canonical request pipeline** (every `/api` call, in order — first failure short-circuits):
  - **1 · Authn** — validate session/token. No session or invalid/expired → `401`. A missing `x-dealer-id` header is **NEVER** a `401` on its own (see NC-14).
  - **2 · Dealer resolution** — resolve `activeDealerId` from `x-dealer-id`; if header present it MUST be in the caller's `dealer_users` memberships, else → `403` (authenticated but not a member of that dealer — treated identically to RBAC denial, no existence leak of the dealer). Header absent → NC-14 resolution below.
  - **3 · Tenant status** — if `dealers.status = suspended`: data-plane **writes** blocked → `423`; reads allowed. `provisioning`/`offboarding`/`closed` gate per module policy.
  - **4 · RBAC** — evaluate `role_permissions(module, category)` for the resolved dealer scope. Denied → `403`. Field-level masking (`hidden|view|edit`) applied to the projection.
  - **5 · Entitlement / feature-flag gate** (NC-9, **AFTER** RBAC) — if the target module or agent is not entitled for this dealer → `404` (hidden, indistinguishable from "does not exist"; NOT `403`). Enforced server-side, never UI-only. Invariant **INV-ENT-1**.
  - **6 · Idempotency** (mutations only, NC-7) — see Key fields; completed replay → stored response, in-flight dup → `409`, key-reuse-with-different-body → `422` `key_reuse_mismatch`.
  - **7 · Validation** — Zod (derived from OpenAPI 163 paths). Malformed body/params → `422`; unmet stage gate → `422 {unmet:[]}`. Malformed/unresolvable dealer on a mutation → `400` `dealer_required`.
  - **8 · Rate limit** — exceeded → `429` + `Retry-After`.
  - **9 · Resource scoping** — every query is filtered by `activeDealerId`. A resource id that exists but belongs to another tenant is invisible → `404` (id not found WITHIN active dealer scope). **NEVER** `403` for a foreign row — that would leak existence.
  - **10 · Handler** — executes inside a DB transaction; external calls (GCS/SMTP/LOS) run OUTSIDE any open transaction via SAGA (NC-11).
- **NC-14 missing `x-dealer-id`**: data-plane `GET` → default-dealer resolution order: **lastActive** → **sole membership** → else return **picker payload** `200` (no error). Mutation with no resolvable active dealer → `400` `dealer_required`. Never `401` for the missing header alone.
- **Impersonation** (NC-10): super-admin impersonation is READ-ONLY by default, time-boxed (≤60m), reason-logged, audited via `impersonatedBy`. Writes require explicit elevation; money-posting, gate-resolution, and customer-sends are HARD-BLOCKED even when elevated.
- **Two planes**: Platform Console (control-plane, `/platform/*`, super-admin) vs Dealer Workspace (data-plane, dealer-scoped by `activeDealerId` + `x-dealer-id`). Dealer-scope EVERYTHING incl concierge, audit, storage.

**⚙️ Agents / automation**

- **Deterministic SYSTEM actions** (plain code, NOT LLM, run inside the transactional flow — **not** "AI writes", **not** kill-switchable): `A2 round_robin` (lead assignment), `A3 quote_tax` (dealer-tax/GRA duty computation, server-computed — no fabrication), `A11 vin_allocation` (deterministic VIN lock on deal commit — NOT a gate).
- **Idempotency store** `idempotency_keys`: key + request-body hash + stored response; drives replay/409/422 behavior (NC-7).
- **SAGA orchestration** (NC-11) for multi-step flows (provisioning, delivery): durable per-step markers + per-step compensation; NEVER hold a DB transaction across an external call (GCS/SMTP/LOS). Provisioning holds `dealers.status=provisioning` until complete.
- **Entitlement resolver**: server-side feature-flag check (INV-ENT-1) that maps dealer → entitled modules/agents; unentitled target yields `404`.

**🧠 AI for the persona**

- **Autonomous LLM writers** (internal-only, audited, kill-switchable) — the ONLY three AI writers: `A1 intake_dedup`, `A6 call_sentiment`, `A16 case_classifier`. (`A2/A3/A11` are deterministic system actions, NOT AI — see automation.)
- **HITL / advisory LLM** (never write/send without a human): `A5 doc_prefill`, `A7 outreach` (Approve & Send), `A10 test_drive_availability`, `A15 pipeline_suggestions`, `sentiment_digest`, `persona_recommend`, `concierge` (nav-only), `gra_extract` (extracts legible fields only → routes to human `gra_filing` gate).
- **Kill-switch** via `isAgentEnabled(semanticKey)`. Valid semantic keys: `intake_dedup, call_sentiment, case_classifier, doc_prefill, outreach, test_drive_availability, pipeline_suggestions, sentiment_digest, persona_recommend, concierge, gra_extract`. There is NO "A1–A27" range — this catalog IS the complete list.
- **Governance** (NC-13): the kill-switch is a platform-reserved **governance** capability — NOT grantable via `/admin/roles` and NOT equivalent to `settings:admin`.
- Model: Anthropic `claude-sonnet-4-6`. All agent runs recorded in `agent_runs`; every autonomous write audited.

**🔑 Key fields · validations · SLA**

- **Status-code contract (NC-1)**: `401` no/invalid session · `403` RBAC denial AND non-member `x-dealer-id` · `404` id not found within active dealer scope (hides cross-tenant rows AND unentitled modules — no existence leak) · `409` idempotency in-flight/dup OR write conflict · `422` validation / unmet gate `{unmet:[]}` / `key_reuse_mismatch` · `423` suspended (writes) · `429` +`Retry-After` · `202` accepted async (enquiries, remind, export, outreach) · `400` malformed/unresolvable dealer on mutation `dealer_required`.
- **Never** return `403` for a foreign resource row and **never** `401` solely for a missing `x-dealer-id`.
- **Idempotency-Key** (NC-7): required on all mutations; stored with body hash in `idempotency_keys`.
- **RBAC modules (NC-5)**: `leads, customers, deals, quotes, bookings, inventory, billing, finance, deliveries, service, parts, gra, reports, dashboard, agents, communications, documents, search, settings, platform, audit`. Categories `view|create|edit|delete|admin`; field-level `hidden|view|edit`.
- **Reference map (NC-2)**: `#r1` Data Model · `#r2` State Machines · `#r3` Agent Catalog · `#r4` RBAC & API/Error Conventions · `#r5` Reports & BI · `#r6` Notifications Matrix · `#r7` Integration Contracts · `#r8` PDF Templates · `#r9` Corrected-Design Deltas · `#r10` Privacy/Retention/Data-Subject Rights.
- **Money**: USD-scale storage, GYD display ×`usdExchangeRate`(~209); VIN/engine 17 chars; registration `^[A-Z]{3}[0-9]{1,4}$`; GRA duty server-computed (no fabrication). NO payment gateway.
- **Honesty scope (NC-12)**: "foolproof" = application-logic correctness + tenant/money/AI invariants. NFRs (DR/backup, encryption-at-rest, HA/uptime, tracing, message broker) are PENDING-INFRA (pre-GA blockers); spec does NOT claim production/NFR readiness. `r9` = defects in the BUILT app + corrected mandate (status to-fix); `V4` = residual open items of spec/infra.
- **Impersonation SLA (NC-10)**: TTL ≤60m, reason mandatory, `impersonatedBy` logged.

**🔀 Edge-of-edge cases → handling**

| Scenario | Detection | Handling | Owner | HITL? |
| --- | --- | --- | --- | --- |
| `x-dealer-id` for a dealer the caller is NOT a member of | membership lookup miss in `dealer_users` | `403` (same as RBAC denial); do NOT reveal whether dealer exists | pipeline step 2 | No |
| Valid session requests a resource id owned by another tenant | row exists but outside `activeDealerId` | `404` (never `403`) — no existence leak | pipeline step 9 | No |
| Missing `x-dealer-id` on a data-plane GET | header absent | resolve lastActive→sole→picker payload `200`; never `401` | pipeline step 2/NC-14 | No |
| Missing/unresolvable dealer on a mutation | no header, no default | `400` `dealer_required` | pipeline step 7 | No |
| Caller has RBAC but module not entitled for dealer | entitlement gate after RBAC | `404` (hidden); enforced server-side, INV-ENT-1 | pipeline step 5 | No |
| Retry after client timeout, same key completed | stored response present | return stored response `200/202`, no re-execute | idempotency store | No |
| Two concurrent requests, same `Idempotency-Key` | in-flight marker | second → `409` | idempotency store | No |
| Same key reused with mutated body | body-hash mismatch | `422` `key_reuse_mismatch` | idempotency store | No |
| Write to suspended tenant | `dealers.status=suspended` | `423`; reads still served | pipeline step 3 | No |
| Admin tries to grant agent kill-switch via `/admin/roles` | governance capability requested in role grid | reject — not grantable here; distinct from `settings:admin` (NC-13) | platform governance | No |
| Impersonating super-admin attempts money-post / gate-resolve / customer-send | impersonation flag on session | HARD-BLOCK even if elevated; audit attempt | impersonation guard | Yes (blocked) |
| Impersonation session exceeds 60m | TTL check | token expires, revert to read-only/none; audited | impersonation guard | No |
| External call (GCS/SMTP/LOS) fails mid multi-step | SAGA step marker | per-step compensation; no DB txn held across the call (NC-11) | SAGA orchestrator | No |
| Kill-switched autonomous agent (A1/A6/A16) invoked | `isAgentEnabled(key)=false` | skip agent write; flow proceeds without AI enrichment; logged | agent runtime | No |
| Rate limit breached | counter over quota | `429` + `Retry-After` | pipeline step 8 | No |

**📄 Documents / artifacts**

- **Error envelope**: uniform `{code, message, ...detail}` — e.g. `{unmet:[]}` (422 gate), `dealer_required` (400), `key_reuse_mismatch` (422).
- **Picker payload** (NC-14): dealer-selection list returned `200` when no default dealer resolvable on a data-plane GET.
- **Audit record**: every mutation, agent write, gate resolution, and impersonation action → `audit_logs` (incl `impersonatedBy`), dealer-scoped.
- **Idempotency record**: `idempotency_keys` (key, body-hash, stored response, state).
- **Entitlement manifest**: per-dealer module/agent feature-flag set backing INV-ENT-1.
- **OpenAPI 163-path contract** → Zod schemas → react-query hooks (single source for request/response shapes).
