# Layer 1 — Lead Capture (New) Sales Advisor

**🚦 Flow (step-by-step, lowest level)**

- **1. Channel arrives.** Five real intake paths, all resolved to a `dealerId` + `divisionId` before any write: (a) public site form → `POST /api/enquiries`; (b) Meta Lead Ads → `POST /api/webhooks/meta`; (c) WhatsApp guided bot → `POST /api/webhooks/whatsapp` or `/api/webhooks/twilio/whatsapp`; (d) Gmail inbound → IMAP poll every 2 min → AI classify; (e) walk-in / phone → advisor manual `POST /api/leads`.
- **2. Tenant + division resolve.** Public/webhook routes have no session, so `dealerId` is derived from the form target / Meta page-id / WhatsApp phone_number_id / inbox address mapping (NOT from a header). Every subsequent query is scoped by this `activeDealerId(res)` — **Correction (1)**. Unresolvable target → reject, no cross-tenant leak.
- **3. Guard untrusted text.** Inbound free-text (message body, email body, subject, form "message", uploaded doc text) is wrapped with `guardUntrusted()` before it ever reaches an LLM prompt — **Correction (4)**. Raw text is still stored verbatim; only the model-facing copy is fenced.
- **4. Agent A1 (Intake/Dedup) fires.** Kill-switch check `isAgentEnabled('A1')` → if paused, lead is created raw with no enrichment. A1 normalizes phone (E.164 Guyana `+592`), lowercases email, classifies channel/source, extracts `selectedModel`/interest, and runs dedup.
- **5. Dedup (email + phone).** Scoped lookup within `dealerId`: match on normalized email OR phone against open `leads` and `customers`. Exact match on an open lead → **merge** (append `timeline_events`, add interest, do not create duplicate). Match on closed/won lead → **reopen** (new lead, `parentAccountId`/prior lead linked, `status=new`, phase reset). No match → create new.
- **6. Confidence floor.** If A1 classification confidence < `MIN_AGENT_CONFIDENCE` (dedup ambiguous, model unrecognized, business vs person unclear) → do NOT auto-merge/auto-classify; create lead with `status=new`, flag `needsReview`, route to human queue — **Correction (3)**.
- **7. Round-robin assign (A2, deterministic).** Pick eligible `dealer_users` in the matching `divisionId` with role permission, ordered by oldest `lastLeadAssignedAt`; set `assignedTo`/`ownerUserId`, bump that user's `lastLeadAssignedAt=now()`. Not an LLM.
- **8. Auto-quote / code (A3, deterministic).** If `interestedVehicleId` or `selectedModel` resolves to priced inventory, A3 runs the tax engine off `dealer_taxes` and pdfkit to produce a first quote version (`quoteNumber`, `status=current`). If nothing resolves, quote is skipped (advisor generates later at Layer 2).
- **9. Notify.** Owner notification via `notifications` + optional acknowledgement to the customer through the unified `email_logs` outbox (email or WhatsApp, retry/backoff/dedupeKey). Auto-reply is a template send, never an LLM free-write.
- **10. Timeline + audit.** `timeline_events` row per action (`isAgent=true` for A1/A2/A3). Every A1 run recorded via `recordAgentRun` into `agent_runs` with PII-minimized `inputSummary`/`outputSummary` — **Correction (5)**. Advisor now sees the lead in the Workflow console with the single primary CTA `Advance to Contacted`.

**⚙️ Agents in play**

- **A1 Intake / Dedup** (claude-sonnet-4-6, **autonomous-write → declared, audited, kill-switchable**). Trigger: `POST /enquiries`, Meta/WhatsApp webhook, Gmail IMAP classify. Grounded inputs: guarded inbound text + scoped `leads`/`customers` (email+phone) for dedup, `vehicles` for model resolution, `lead_sources` for source. Output: `{channel,source,selectedModel?,interestedVehicleId?,dedupDecision:"new|merge|reopen",matchLeadId?,confidence}`. HITL: **no** above floor (autonomous create/merge); **yes** below `MIN_AGENT_CONFIDENCE` → `needsReview` queue. Audited via `recordAgentRun`.
- **A2 Round-robin assign** (deterministic, not LLM). Trigger: on lead create / `POST /leads/:id/assign`. Inputs: `dealer_users` filtered by `divisionId` + role, ordered by `lastLeadAssignedAt`. Output: `{assignedTo}` + clock bump. HITL: **no** (manager may reassign manually).
- **A3 Quote / Code** (deterministic tax engine + pdfkit). Trigger: creation with resolved priced vehicle. Inputs: `vehicles.price`, `dealer_taxes` (VAT 0%/14%, duty, EV exclusion), `dealer.usdExchangeRate`. Output: `quotes` row + PDF. HITL: **no** to generate; human sends.
- **A15 Pipeline suggestions** (read-only). Trigger: `GET /pipeline/suggestions`. Inputs: real leads in phase=new. Output: ranked next-action hints. HITL: advisory only.

**🧠 AI for the persona**

- New-lead card shows A1-derived **channel/source badge**, resolved `selectedModel`, and a **confidence chip**; low-confidence leads carry a "Needs review — verify match" banner instead of an auto-merge.
- `aiScore` (lead quality) surfaced as a sortable column so the advisor works hottest leads first; score is a hint, never a gate.
- Pipeline suggestion strip: "3 new leads unworked > 2h — call now" from `GET /pipeline/suggestions`.
- Detected `preferredLanguage` (EN / Guyanese Creole) shown so the advisor picks the matching outbound template; A1 never machine-translates the stored text, only tags it.
- Concierge (`/anthropic` SSE, `/copilotkit` nav-only) can answer "show my new leads today" — grounding is **dealer-scoped**, no cross-tenant rows, no mutations.

**🔑 Key fields · validations · SLA**

- `leads`: `channel`, `source`+`sourceDetail`, `phase=new`, `status=new`, `priority`, `interestedVehicleId`, `selectedModel`, `ownerUserId`, `assignedTo`, `aiScore`, `stageEnteredAt`, `preferredLanguage`, `needsReview`.
- **Validations:** email RFC + lowercased; phone → E.164 `+592`; at least one of email/phone required; `fullName` non-empty; `source` ∈ active `lead_sources`; `interestedVehicleId` must exist and be same-tenant + not `sold/delivered`; `selectedModel` free-text allowed but flagged if not in inventory; `divisionId` ∈ dealer's CAM/GT.
- **Money/dates:** quote money stored USD-scale, GYD display = amount × `dealer.usdExchangeRate` (~209); `stageEnteredAt`, `validUntil` in America/Guyana GMT-4.
- **Config touched:** `stage_checklists` (versioned) defines "new→contacted" gate keys (e.g. `contact_attempted`); `dealer_taxes` feeds A3; `MIN_AGENT_CONFIDENCE` floor; A1 kill-switch in `agents`.
- **SLA timers:** first-response target (e.g. 15 min business hours) measured from `stageEnteredAt`; breach raises a `task` + owner `notification`. WhatsApp bot session idle → auto-close conversation after configured window. Gmail poll = 2 min. Outbox retry with backoff on send failure.

**🔀 Edge-of-edge cases → handling**

| Scenario | Detection | Handling | Owner | HITL? |
| --- | --- | --- | --- | --- |
| Duplicate submit within seconds | Same email+phone+dealer within dedupe window | A1 merge into existing open lead; append timeline; return `merged:true` | A1 | No |
| Dedup ambiguous (same phone, different name) | A1 confidence < `MIN_AGENT_CONFIDENCE` | Create new lead `needsReview=true`; do not merge; route to human queue | Sales Advisor | Yes — verify/merge |
| Reopened lead (prior won/lost) | Match on closed lead | New lead linked to prior + `customer`; status=new; phase reset; note "reopened" | A1 | No |
| Multi-model interest | Body lists 2+ models | Store primary `selectedModel`; extra interests as `customer_notes`/timeline; one lead, not many | A1 | No |
| Fleet / PO (business account) | `accountType=business` or qty >1 | Set high `priority`; flag capital-order path (gate `capital_order` at deal stage); route to fleet advisor if configured | Sales Manager | Yes — route |
| Cross-tenant leak attempt (spoofed `x-dealer-id` / wrong page-id) | Resolved dealer ≠ record tenant | 404/reject; every query scoped by `activeDealerId`; audit | Platform | No |
| WhatsApp opt-out ("STOP") | Inbound keyword | Mark conversation opted-out; suppress outbound in outbox; keep lead, flag no-contact | System | No |
| Outbound WhatsApp/email delivery failed | Outbox status failed after retries/backoff | Dedupe-keyed retry; on exhaustion raise `task` + notification to owner | Sales Advisor | Yes — alt channel |
| Interested vehicle sold/soft-lock expired before contact | `vehicles.status≠available` / `holdUntil` passed | Flag lead; A15/A3 suggest comparable available unit; block auto-quote on unavailable VIN | Sales Advisor | Yes |
| Concurrent assign (two managers) | Row version / `lastLeadAssignedAt` conflict | Optimistic lock; last write on clock wins; single `assignedTo` | System | No |
| Prompt-injection in inbound text | `guardUntrusted` fence | Text passed fenced; model instructed to treat as data; raw stored, never executed | System | No |
| Gmail non-lead / spam | A1 classify = not-a-lead below floor | No lead created; logged in `agent_runs`; optional review inbox | A1 | No |
| Agent A1 killed (kill-switch) | `agents.status=paused` | Lead created raw, no enrichment/dedup; banner "manual triage"; assign still runs (A2 deterministic) | Sales Advisor | Yes — manual |
| Creole-only message | A1 language tag | Tag `preferredLanguage=creole`; store verbatim; advisor uses Creole template; no auto-translate of stored text | Sales Advisor | Yes — reply |
| Malformed/partial form (no email & no phone) | Validation | 400 reject; no lead; nothing queued | System | No |
| No advisor available in division | Empty eligible set | Assign to division pool/manager; `needsReview`; notify manager | Sales Manager | Yes |

**📄 Documents & PDF format**

- **Auto-Quote PDF** — generator `pdfkit` (`quote-pdf.ts`), stored via `quotes`, delivered through unified `email_logs` outbox (email or WhatsApp) only on human "Send". Layout: **Header** — dealer logo (CAM Motors / GT Automotive), division, `quoteNumber`, quote date + `validUntil` (GMT-4), advisor name. **Customer block** — name, phone, email. **Vehicle block** — make/model/trim/year, VIN if allocated, accessories[]. **Line items** — columns: Description · Qty · Unit (GYD) · Amount (GYD), with base price, accessories, discount as negative line. **Tax section** — `taxLines[]` from `dealer_taxes` (VAT 0%/14% by model, import duty, excise; EV duty excluded) computed **server-side deterministically**, never model-invented. **Totals** — subtotal, total tax, `total` (GYD display = USD × `usdExchangeRate`). **Footer** — validity note, dealer TIN, terms, "quote not an invoice", page number.
- **Inbound uploaded docs** (e.g. licence/ID at capture) — stored polymorphic `documents` (lead), text run through `guardUntrusted`; A5 vision may pre-fill allowlisted `PREFILL_FIELDS` with `extractionStatus:"proposed"` — HITL confirm at `/documents/extraction/review`. No GRA/tax figures fabricated here — GRA filing is a later gated step.
- **Auto-acknowledgement message** — templated HTML (email) / text (WhatsApp) from `emails/templates`, language-matched (EN/Creole), sent via outbox with `dedupeKey`; not an LLM free-write.
