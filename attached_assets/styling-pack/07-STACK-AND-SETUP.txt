CHOICE

Framework

React 18/19 + TypeScript (strict)

Vite 7 ( @vitejs/plugin-react )

Tailwind CSS v4 ( @tailwindcss/vite , no tailwind.config.js — CSS-first via @theme )

lucide-react (+ react-icons if needed)

react-hook-form + zod ( @hookform/resolvers )

Toasts

sonner

Class utils

clsx + tailwind-merge (the cn() helper)

Tables/UX

switch

4. Config files
vite.config.ts

import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";
import path from "path";

export default defineConfig({
plugins: [react(), tailwindcss()],
resolve: {
alias: { "@": path.resolve(import.meta.dirname, "src") },
dedupe: ["react", "react-dom"],
},
});

src/main.tsx

import { createRoot } from "react-dom/client";
import App from "./App";
import "./index.css";

// = theme.css

createRoot(document.getElementById("root")!).render(<App />);

Tailwind v4 note: there is no tailwind.config.js . All theming is CSS-first via @theme inline { … } and
:root / .dark variables in theme.css . Just @import "tailwindcss" and the plugins. Dark mode = a .dark

class on <html> (toggle with next-themes or manually).

5. Install & run
npm create vite@latest my-app -- --template react-ts
cd my-app
# paste deps into package.json, then:
npm install
npx shadcn@latest init

# choose new-york, neutral, css vars

npx shadcn@latest add button card dialog dropdown-menu input tabs tooltip \
popover select badge sheet scroll-area separator sonner command table \
textarea progress avatar skeleton

# …and the rest from 03-COMPONENTS.md

# replace src/index.css with 02-theme.css
npm run dev
