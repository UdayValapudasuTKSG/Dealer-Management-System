3. Key System Controls & Operational Integrity
3.1 Concurrent Shipment Editing (Pessimistic Locking)
To prevent race conditions, duplicate allocations, and data corruption when multiple dealership staff access the shipment module simultaneously:
Single-User Active Edit Lock: Only one user at a time can hold write privileges for a specific shipment section or record.
Read-Only Access for Concurrent Users: Additional staff opening the same shipment will see a read-only view with a clear active lock notification indicating which user is currently editing.
Lock Timeout & Release: Automatic session timeouts release locks after inactivity to prevent abandoned records.
3.2 Import Error Handling & Data Validation Strategy
Based on operational feedback, the initial "reject-all" strict policy has been relaxed to support operational efficiency:
Partial Rejection Permitted: During bulk CSV/XLSX imports (shipment lines or VIN manifests), valid rows are accepted and processed while invalid rows are isolated into a downloadable error report.
Row-Level Error Reporting: The system highlights exact row numbers and validation failure reasons (e.g., duplicate VINs, unknown color variants, non-positive quantities) for quick re-upload.
Atomic Execution per Valid Row: Partial processing must not create orphan records or duplicate customer claims.
