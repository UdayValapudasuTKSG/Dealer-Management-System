# Module A — Inventory Management Inventory / Sales Manager

**🚦 Flow (lowest level)**

- **Every read/write is dealer-scoped.** Manager authenticates (Clerk) → `auth/me` resolves **users.clerkId → dealer_users(activeDealerId, divisionId, isGeneralManager)**. Middleware sets `activeDealerId(res)` and requires header `x-dealer-id`; the two MUST match or **403**. Every Drizzle query on `vehicles`, `dealer_taxes`, `part_purchases`, storage objects and audit-logs carries `where dealerId = activeDealerId` — no cross-dealer bleed (CAM vs GT).
- **Browse/filter stock:** `GET /api/vehicles?status=&make=&model=&year=&powertrain=&division=&q=` → paged list scoped to dealer. Non-GM managers additionally filtered/soft-flagged by their `divisionId` (CAM/GT) unless role grants cross-division view. Field visibility applies `role_field_permissions` (e.g. `cost`, `documents[]` may be **hidden|view|edit**).
- **Create vehicle:** Manager opens New Vehicle → enters `make, model, trim, year, vin, engineNumber, registration, price(USD-scale), powertrain, division`. Client shows GYD preview = `price × dealer.usdExchangeRate(~209)` (display only; stored USD-scale). On blur of VIN/engine → decode+validate (17-char, checksum region). `POST /api/vehicles` → **201** with `status='available'` default. Duplicate `(dealerId, vin)` → **409**.
- **Photo/360 video upload:** Client calls `POST /api/storage/uploads/request-url` {contentType, ext, purpose:'vehicle-image'} → server returns short-TTL presigned PUT URL (GCS via Replit sidecar) with object path namespaced `dealers/{dealerId}/vehicles/{vehicleId}/…`. Browser PUTs bytes direct to GCS. Server writes ACL row (dealer-scoped, module='vehicles') and appends the object key to `vehicles.images[]` (or a 360 `documents[]` entry) via `PATCH /api/vehicles/:id`. Reads go through `GET /api/storage/objects/*` which re-checks dealer ACL before signing a GET URL.
- **Bulk import:** Manager downloads `GET /api/vehicles/import/template` (ExcelJS .xlsx with typed columns + data-validation dropdowns for powertrain/status/division). Fills, uploads via `POST /api/vehicles/import` (multipart). Server parses row-by-row, validates, upserts by `(dealerId, vin)`, returns per-row result report {inserted, updated, skipped, errors[{row, field, msg}]}. All-or-nothing per row; malformed rows reported, never silently dropped.
- **Pricing master:** Manager maintains `dealer_taxes` via `admin/taxes` (VAT 0%/14%, import duty, excise/levy, EV battery duty, threshold, `excludeEv`). Price shown on a vehicle detail composes **server-computed** line items — client never computes tax. Same deterministic engine feeds quotes/deals (Agent A3).
- **Status machine + soft-lock:** Manager changes status through validated transitions only (`VEHICLE_STATUS_TRANSITIONS`). Placing a hold sets `holdUntil`+`holdReason` (soft-lock: still visible, not bookable). Deal commit hard-locks via VIN allocation (Agent A11) → `reserved/booked`. Delivery advance → `delivered→sold`.
- **Book-from-stock:** From an available vehicle → Book → creates `bookings` row (`vehicleId, bookingAmount, expiresAt`), flips vehicle `available→reserved` atomically. Expiry worker reverts `reserved→available` when `bookings.status='expired'`.
- **Stock-mix / reorder / remarketing:** Manager opens Inventory dashboard tiles fed by `GET /api/dashboard/inventory-breakdown` and `GET /api/pipeline/suggestions` (Agent A15) → surfaces slow-movers (aged stock), reorder gaps, disposal candidates. Disposal = status transition to a terminal/remarket state + audit; capital re-order raises a `gates(type=capital_order)` approval.

**⚙️ Agents in play**

- **A15 Pipeline / Stock-mix suggestions** → trigger: dashboard load or scheduled → grounded inputs: dealer-scoped `vehicles` (age = now − createdAt, `status`, `powertrain`, `price`), historical sales velocity, `reorderLevel` patterns → output: ranked slow-mover/reorder/disposal suggestions written to `agent_runs` (confidence, latency) → **HITL**: advisory only; below `MIN_AGENT_CONFIDENCE` suppressed to human; capital re-order acted on only via `gates(capital_order)` approval. Kill-switch `isAgentEnabled` + `recordAgentRun`.
- **A11 VIN allocation** → trigger: deal commit (Module: Deals) → deterministic pick of a specific `vehicles.vin` from available stock of `selectedModel`, hard-locks `available→reserved/booked` → output: VIN-locked deal + `timeline_events` → **HITL**: none (deterministic), but writes audited; conflict → gate. Shown here because it consumes/mutates inventory status.
- **A3 Quote/Code (deterministic tax)** → not inventory-owned but reads `vehicles.price` + `dealer_taxes` to compose server-side pricing; listed so managers know the price shown on a vehicle uses the SAME deterministic engine (no AI invents tax).
- **GRA vision extract** (`/api/gra/extract`) → if a manager uploads an import/customs doc against a vehicle, AI extracts **legible fields only** (year/make/model/mileage) → SERVER computes duty from `dealer_taxes` → human `gates(gra_filing)` confirms. AI NEVER invents TIN/VIN/CIF/duty; untrusted OCR text wrapped with `guardUntrusted`; below confidence → human. All under kill-switch + `recordAgentRun`.

**🧠 AI for the persona**

- **Stock health at a glance:** A15 flags aged units, over/under-stocked segments (e.g. EV vs ICE mix), and reorder gaps vs `parts.reorderLevel`-style thresholds — always dealer- and division-scoped, always with a confidence badge; low-confidence items are hidden, not guessed.
- **Disposal/remarketing hints:** Suggested remarket candidates ranked by days-in-stock and margin pressure; the manager decides — action requires a status transition + (for capital) an approval gate.
- **VIN/engine decode assist:** Decode is deterministic validation (17-char, region/checksum), not generative — surfaces make/model/year hints for confirmation; the human accepts. AI never overwrites a manually entered VIN.
- **Guardrails:** Every AI touch obeys `isAgentEnabled` kill-switch, is audited via `recordAgentRun`, PII-minimized, and any external/OCR text passes `guardUntrusted`. Outputs below `MIN_AGENT_CONFIDENCE` route to a human.

**🔑 Key fields · validations · SLA**

- **VIN & engineNumber:** exactly 17 chars, uppercase alphanumeric, no I/O/Q; VIN unique per `(dealerId, vin)`. **422** on format, **409** on duplicate.
- **registration:** `^[A-Z]{3}[0-9]{1,4}$` (Guyana plates), unique per dealer where set.
- **price:** stored USD-scale (integer minor units); GYD display = `price × dealer.usdExchangeRate(~209)`, computed at render, never persisted in GYD. Dates America/Guyana (GMT-4) incl. `holdUntil`, `bookings.expiresAt`.
- **powertrain:** enum (ICE/hybrid/EV…); drives EV duty exclusion (`dealer_taxes.excludeEv` / battery duty).
- **status:** `available|reserved|booked|delivered|in_transit|sold|service`. Transitions enforced by `VEHICLE_STATUS_TRANSITIONS`; illegal jumps → **422**. `holdUntil/holdReason` = soft-lock (visible, unbookable); deal-commit VIN-lock = hard-lock.
- **divisionId:** CAM/GT tag; non-GM managers scoped to their division unless role permits cross-division.
- **images[] / documents[] / accessories[]:** JSON arrays of GCS object keys / structured items; keys namespaced `dealers/{dealerId}/…`; served only via ACL-checked signed URLs.
- **Tax composition:** deterministic, server-side from `dealer_taxes` (VAT 0/14%, import duty, excise/levy, EV exclusion, threshold). Client sends none; GRA = Guyana Revenue Authority (GYD).
- **SLA:** presigned URL TTL short (~minutes); import parse target < a few seconds for typical dealer sheet; A15 suggestions refreshed on dashboard load / scheduled; booking expiry worker reverts stock promptly after `expiresAt`.

**🔀 Edge-of-edge cases → handling**

| Scenario | Detection | Handling | Owner | HITL? |
| --- | --- | --- | --- | --- |
| Same VIN in import sheet twice / already in DB | upsert key (dealerId,vin) collision | Update existing row (later wins within file); cross-file dup reported in errors[]; never create second vehicle | Import parser | Yes — review report |
| VIN belongs to another dealer | uniqueness is per-dealer; header/scope mismatch | Allowed in own dealer only; **403** if x-dealer-id ≠ activeDealerId; no cross-dealer lookup | Scope middleware | No |
| Malformed row in xlsx (bad year, bad plate, missing powertrain) | Zod per-row validation | Row skipped, added to errors[{row,field,msg}]; valid rows still committed | Import parser | Yes — fix & re-upload |
| Book a vehicle that just got reserved | tx re-reads status | Atomic guard → **409** not available; UI refreshes | Bookings tx | No |
| Hold expired but never released | `holdUntil` < now | Worker/derived state treats as not-held; soft-lock lifts; can re-book | Expiry worker | No |
| Delete vehicle linked to open deal/asset/delivery | FK / relation check | **409** block; must resolve deal first; else archive (soft) | Vehicles API | Yes |
| Illegal status jump (e.g. sold→available) | VEHICLE_STATUS_TRANSITIONS | **422** with allowed next states; no write | Status machine | No |
| Presigned URL reused / cross-dealer object read | ACL row check on GET | Short TTL + `GET /storage/objects/*` re-verifies dealer ACL → **403** | Storage ACL | No |
| Import doc OCR suggests a duty/CIF value | GRA extract confidence + field allowlist | AI extracts legible fields only; server computes duty from dealer_taxes; below MIN_AGENT_CONFIDENCE → human; guardUntrusted wraps text | A-GRA + server | Yes — gra_filing gate |
| Capital re-order of new stock | disposal/reorder action > threshold | Raises `gates(capital_order)`; blocked until approved with evidence[] | Manager + approver | Yes |
| usdExchangeRate changes mid-day | dealer config update | USD stored unchanged; GYD display recomputes on next render; historical quotes keep their own totals | Pricing render | No |
| 360 video too large / wrong type | request-url contentType/ext + GCS size cap | Reject at request-url or PUT; key not appended to documents[] | Storage API | No |

**📄 Documents & PDF format**

- **Import template (.xlsx, ExcelJS):** single sheet, header row with typed columns (make, model, trim, year, vin, engineNumber, registration, price(USD), powertrain, divisionId, accessories) + data-validation dropdowns for powertrain/division/status; example row + notes row; returned as attachment from `/vehicles/import/template`.
- **Import result report:** JSON {inserted, updated, skipped, errors[{row,field,msg}]} rendered as a table in UI; downloadable.
- **Vehicle media:** `images[]` (JPEG/PNG) + optional 360 walkaround video in `documents[]`, all stored in GCS under `dealers/{dealerId}/vehicles/{vehicleId}/…`, served via ACL-checked signed URLs only.
- **Customs/import docs:** polymorphic `documents` rows (target=vehicle) with `extraction` jsonb + `extractionStatus`; GRA vision extract populates legible fields for human confirmation.
- **No inventory-specific PDF is generated here** — pricing feeds pdfkit quote/delivery PDFs downstream (Modules Deals/Delivery); tax lines on those PDFs come from the same deterministic `dealer_taxes` engine, in GYD with USD-scale source.
