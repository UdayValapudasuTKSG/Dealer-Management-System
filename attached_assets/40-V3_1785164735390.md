# Validation V3 — System Invariants & Guarantees

This section enumerates the **machine-checkable invariants** that constitute AURA's honesty envelope. Each invariant is (a) stated as a universally-quantified guarantee, (b) mapped to its server-side enforcement point in the request pipeline or transactional flow, (c) bound to a canonical failure code from [r4](#r4)/**NC-1**, and (d) covered by at least one negative test in the suite at the end of this section. Invariants are *application-logic + tenant/money/AI* guarantees only; NFR readiness is explicitly out of scope (see [INV-HON](#INV-HON) and [r9](#r9)/V4). Where an invariant references a state value, an agent, a gate type, or an RBAC module key, the value is the one defined in [r2](#r2), [r3](#r3), **NC-4**, and **NC-5** respectively — this section restates none of those enums, it only references them.

## V3.0 — Pipeline enforcement order (where invariants fire)

Every data-plane request traverses a fixed middleware chain. Invariant enforcement is anchored to a specific stage so that failure codes are deterministic and non-leaking:

- **Session** — no/invalid session → **401**. A missing `x-dealer-id` header is *never* 401 (**NC-14**).
- **Dealer resolution** — resolve active dealer from `x-dealer-id`; if absent on a GET, run default-dealer resolution (`lastActive` → sole membership → else return picker payload **200**). On a mutation with no resolvable dealer → **400 dealer_required**.
- **Membership** — `x-dealer-id` not in caller memberships → **403** (authenticated but not permitted).
- **RBAC** — module/category permission check against `role_permissions` (**NC-5**) → **403** on denial.
- **Entitlement / feature-flag gate** (**NC-9**, after RBAC) — target module/agent not entitled for the dealer → **404** (hidden). See [INV-ENT-1](#INV-ENT-1).
- **Suspension** — `dealers.status = suspended` blocks data-plane *writes* → **423**; reads still allowed.
- **Idempotency** — mutations require `Idempotency-Key` (**NC-7**).
- **Row scope** — resource id not found within active dealer scope → **404** (foreign rows hidden, never 403). See [INV-TEN](#INV-TEN).

| --- | --- | --- | --- | --- |
| **INV-TEN** | No caller ever observes, reads, or mutates a row belonging to a dealer outside its active, membership-authorized scope; cross-tenant existence is never leaked. | Every query is bound by `dealerId = activeDealerId`; membership checked before RBAC; row-scope check after. | **403** membership / **RBAC** denial; **404** for a foreign or non-scoped row (NEVER 403 for a foreign row — no existence leak); **400 dealer_required** on unresolvable mutation; **401** only for no/invalid session (never for a missing header). | [r4](#r4), NC-1, NC-14 |
| **INV-ENT-1** | A module or agent that is not entitled (feature-flagged off) for the active dealer is indistinguishable from non-existent to that dealer — enforced server-side, not merely hidden in the UI. | Entitlement gate runs *after* RBAC and before row scope, server-side on every path touching a gated module/agent. | **404** (hidden). A caller with valid session, valid membership, and sufficient RBAC still receives 404 for a non-entitled target. | NC-9 |
| **INV-GATE** | A human approval gate exists in exactly one of the six canonical types, and no protected transition completes while its gate is `open`. | `gates` rows created at the guarded transition; `gates.status: open → resolved(approve\|reject)` ([r2](#r2)). | **INV-MON** | Monetary computation uses a **single rounding mode** applied **line-then-total**: each line item (unit price, discount, tax via A3 `quote_tax`) is rounded to cents first, then the document total is the sum of already-rounded lines — never round the grand total independently of its lines. | Amounts stored USD-scale; GYD is display-only via `×usdExchangeRate (~209)` and never a stored posting basis. | **INV-IDEM** | Every mutation is exactly-once with respect to its `Idempotency-Key`. | `idempotency_keys` table keyed per dealer; completed replay returns the stored response; in-flight duplicate rejected; same key + different body detected via body hash. | In-flight duplicate → **409**. | **INV-SUSP** | A suspended tenant can read but cannot perform data-plane writes. | Suspension check in pipeline before idempotency/row-scope; `dealers.status` transitions per [r2](#r2) (`provisioning → active → suspended → offboarding → closed`). | Data-plane write while suspended → **423**. Reads → **200**. | NC-1, r2 |
| **INV-IMP** | Super-admin impersonation is read-only by default, time-boxed (≤60m), reason-logged, and audited; money-posting, gate-resolution, and customer-sends are hard-blocked even after explicit write-elevation. | `impersonatedBy` stamped on every action; elevation is explicit and scoped; the three hard-blocked classes are denied unconditionally in the write path. | Impersonated write without elevation → **403**. | **INV-SAGA** | Multi-step flows (dealer provisioning, the 9-step delivery) run as a SAGA with durable per-step markers and per-step compensation; no DB transaction is ever held across an external call (GCS / SMTP / LOS). | Each step commits its own marker; failure triggers compensation of prior steps. | **INV-AI** | Only the three autonomous LLM writers (A1 `intake_dedup`, A6 `call_sentiment`, A16 `case_classifier`) write autonomously; all are internal-only, audited, and kill-switchable. | **INV-RATE** | Rate-limited callers receive a bounded, retriable signal. | Per-caller/per-dealer limiter in the pipeline. | **429** with `Retry-After`. | NC-1 |
| **INV-HON** | "Foolproof" is scoped to application-logic correctness plus the tenant/money/AI invariants above. ## V3.4 — Coverage assertion

Every invariant in the register (V3.1) is exercised by at least one negative test in V3.3, and every canonical status code in **NC-1** (**200, 202, 400, 401, 403, 404, 409, 422, 423, 429**) appears as an expected outcome. Codes referenced by other sections (e.g. [r4](#r4) error conventions, [r6](#r6) notification triggers on gate resolution) MUST match these values verbatim; this section is the invariant authority but defers all enum values to [r2](#r2), **NC-4**, **NC-5**, and **NC-6**.
